# 비포어스 · BEFORE US

> 끌리는 사람을, 천천히 알아갑니다.

운영진이 신청서를 직접 읽고 고른 **한 사람**을, 준비된 날 **정오 12시**에 소개하는 일대일 소개 서비스의 웹 데모입니다.
서로 끌림이 확인되면 두 사람은 **3일 동안** 편지를 나누거나(A) 함께 첫 장면을 고르며(B) 알아가고, 4일째에 각자 만남 의사를 정합니다.

> 이 저장소는 **가상 데이터로 동작하는 데모**입니다. 실제 개인정보 수집, 결제, 메시지 발송, 본인인증은 연결되어 있지 않으며 새로고침하면 입력 내용이 사라집니다.

## 주요 화면

| 경로 | 내용 |
| --- | --- |
| `/` | 공개 홈: 정오 시계, 운영진의 편지, 두 사람의 이야기, 편지·첫 장면 체험, 이용 요금 |
| `/apply` | 4단계 소개 신청 (나에 대해 · 사진 · 원하는 만남 · 공개·동의), 가상 본인·성인 인증 |
| `/today`, `/profile` | 회원 오늘·내 정보: 대기 단계, 프로필 코칭, 일시정지·탈퇴, 정보 권리 요청 |
| `/admin` | 관리자 콘솔 (가상 Owner): 성비 대시보드, 소개·매칭(후보 추천 보조), 신고·안전, 알림 메시지 템플릿 |
| `/demo/...` | 개발용 시연 화면 (교류·약속·결제·노쇼·개인정보 등) |

## 핵심 설계

- **운영진 최종 선택:** 규칙 기반 추천은 양쪽이 직접 입력한 답변이 겹치는 지점을 근거와 함께 보여 줄 뿐이며, 사진·외모·MBTI는 쓰지 않습니다.
- **성비 균형:** 60% 초과 시 경보, 70% 이상이면 많은 쪽 성별의 새 신청을 순차 검토 대기로 받습니다.
- **정책 버전 관리:** 환불(V6-refund-01), 교류 중단·노쇼·재이용(V6-conduct-01), 개인정보 보유·삭제(V6-privacy-01 초안)를 구매·요청 시점 기준으로 적용합니다.
- **개인정보 최소화:** 상대 연락처는 양쪽 동의 시 만남 당일부터 다음 날까지만 표시하고, 메시지에는 상대 정보를 넣지 않습니다.

자세한 운영 기준은 [`guidelines/`](guidelines/) 폴더를 참고하세요.

## 기술 스택

React 18 · TypeScript · Vite 6 · Tailwind CSS 4 · Radix UI(shadcn/ui) · React Router 7

## 로컬 실행

```bash
pnpm install
pnpm dev
```

`http://localhost:8443`에서 열립니다. 배포용 빌드는 `pnpm build` (결과물: `dist/`).

> Windows에서 처음 설치할 때 빌드 도구가 리눅스용만 받아지는 경우, `pnpm-workspace.yaml`의 `supportedArchitectures.os`에 `win32`를 잠시 추가한 뒤 설치하세요.
