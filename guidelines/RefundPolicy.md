# V6-refund-01 — 결제·환불 운영 기준 반영

- 가격과 소개 흐름은 유지한다: 소개비 5,000원 + 교류비 24,000원, 첫 교류까지 1인 29,000원.
- 신규 가상 구매의 `policy.refundPolicyVersion`과 `refundOperations.policy`에 기준을 스냅샷으로 보관한다. 기존 거래·정책·동의 원본은 덮어쓰지 않으며 스냅샷이 없으면 개별 확인이다.

## 소개비

실제 후보 준비·현재 참여·제공 범위를 확인한 후에만 결제 요청을 연다.
첫 소개 확인하기 클릭, 소개 게시 시각, 사진 제공 동의만으로 제공 개시를 기록하지 않는다.
기존 첫 열람 안내를 확인하고 공개 허용 프로필이 실제 화면 영역에 보였을 때만 첫 개시 시각을 한 번 기록한다.

- 실제 첫 열람 전 취소: 5,000원 전액.
- 실제 첫 열람 후: 이미 제공된 소개 서비스분으로 처리하되 오류·필수조건 위반 등 운영 측 귀책에는 전액. 사용자 귀책 주장만으로 운영 확인/실제 환불 완료를 생성하지 않는다.
- 활성 연속 30일 유효한 새 소개 없음: 본인이 계속 이용 또는 전액 환불 종료를 선택한다. 자동 만료/종료/추가금은 없다.
- 유효한 새 소개 공개는 대기 기준을 갱신한다. 정지·철회·탈퇴 요청·차단은 연속 활성 대기에서 제외한다. 기록 없는 과거 대기를 추정하지 않는다.

## 교류비

| 실제 콘텐츠 제공 개시 | 미제공 DAY 산정 |
| --- | --- |
| DAY01 전 | 24,000원 |
| DAY01 후, DAY02 전 | 16,000원 |
| DAY02 후, DAY03 전 | 8,000원 |
| DAY03 후 | 미제공 DAY 환불 없음 |

계획한 날짜/시각 도래만으로 제공을 기록하지 않는다. 기존 양쪽 결제·같은 A/B·시작일 동의·실제 가상 개시 검증과 해당 날짜 콘텐츠의 권한/이용 가능 게이트를 사용한다.
서버 개시 작업은 미구현이며 현재 기록은 명시적 가상 처리에서만 생긴다. 미제출은 미제공과 다르다.

- 상호 선택 후 기본 결제 기한 24시간. 한쪽만 결제하고 상대 미결제면 결제자의 24,000원 전액 환불과 소개 권리 복원 대상.
- 양쪽 유효 승인 기록 이후 A/B·시작일 합의 기본 48시간. 연장 요청자와 상대가 각각 동의하면 24시간 한 번만 연장.
- 양쪽 합의 완료는 실제 교류 시작과 별도다. 합의가 끝나도 실제 미시작이면 전액 환불/소개 권리 유지 기준을 적용한다.
- 기한 도래로 상대 선택·동의·취소·환불 완료를 자동 생성하지 않는다. 현재는 전액 대상과 요청/검토만 표시한다.

## 처리·원장

- 요청과 산정액/근거/정책 버전, 운영 검토, 환불 완료 시각/실제 지급액을 구분한다.
- 요청 클릭은 승인이나 실제 환불 완료가 아니며 `refundedAt`을 만들지 않는다.
- 관리자 원장의 실제 수납액/환불액과 요청 산정액을 분리한다. 과거 전액 환불 기록을 새 부분 환불액으로 바꾸지 않는다.
- 소개 권리는 상호 선택·결제·A/B/시작일 합의만으로 종료되지 않는다. 미시작 전액 환불과 소개 권리 유지/복원 대상 안내는 별도다. 실제 신규 배정 재개·권리 복원 원장·환불 지급은 서버/PG 검증 작업이 필요하다.

## 권리와 미연결 항목

운영 기준은 법정 청약철회와 실제 약관 검토에 따른 더 유리한 권리를 제한하지 않는다.
개시 후 소개비·운영 귀책·미제공 이력 등은 개별 확인이 필요하며 자동 환불 불가 판정을 하지 않는다.
보유기간·재이용·노쇼/약속 취소의 별도 정책은 이번 지시에서 확정되지 않았다.

실제 PG 승인/환불/웹훅, 서버 인증·제공 이벤트·기한 예약·권리 원장·영구 저장과 법률 검토는 미구현이다.
모든 UI와 처리 결과는 가상 자료이며 실제 수집·과금·발송·환불·자동 공개·배포를 하지 않는다.
