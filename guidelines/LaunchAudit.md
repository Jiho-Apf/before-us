# 플라비(FLAVIE) V6 — 출시 전 점검 결과

> 이 문서는 23번 통합 점검 당시의 기록이다. 이후 확정된 결제·환불 운영 기준은 `Guidelines.md` 24번 및 `RefundPolicy.md`가 우선하며, 당시 ‘환불 미확정’ 결과를 신규 정책에 적용하지 않는다. 실제 PG/서버/법률 검토 미구현 구분은 유지한다.

## 결론

현재는 브라우저 메모리의 가상 자료 데모이며 실서비스 출시 준비 완료가 아니다.
‘끌리는 사람을, 천천히 알아갑니다.’와 기존 가격·소개·A/B·약속 흐름을 유지했다.
이번 점검은 기존 구현을 재생성하지 않고 누락된 연결과 검증에서 발견한 결함만 보완했다.

## 실행 범위

- 브라우저: 기존 호스트 개발 서버, Chromium, 360/390 × 844, 가상 자료만 사용.
- 경로: `/`, `/how-it-works`, `/apply`, `/today`, `/us`, `/payments`, `/exchange`, `/meeting`, `/meeting/contact`, `/profile`, `/support`, `/demo/introduction`, `/demo/noon`, `/demo/agreement`, `/demo/letters`, `/demo/scene`, `/demo/meeting`.
- 위 34개 경로·폭 조합과 폭별 첫 열람/워터마크/회원별 확인 유지 흐름 2건: 36건 통과.
- 추가 검증: 폭별 관리자 원본·감사·양방향 비교, 빈 A 개시/긴 한국어 초안/A 오늘, 빈 B 개시/B 오늘, 노쇼 신고 폼, 키보드 본문 건너뛰기. 기존 Pretendard의 사용된 폰트 face 로딩도 확인했다. 검증 환경의 외부 인증서 문제를 우회한 브라우저 컨텍스트이며 서비스 TLS 검증 완료가 아니다.
- 가상 모델: 지역/직업/공개 범위, 양방향 조건, 과거/차단 상대, 대기 기준, 발송 실패 독립성, 감사 동의/중복, 요청 접수, 초기 집계, 연락처 최신 버전/동의/일시/안전·예약 취소 검사.
- 빌드: `pnpm build` 통과. 번들 크기 경고가 남는다.
- 타입 검사: `pnpm exec tsc --noEmit` 실패. 기존 `App.tsx`의 `isFirst`/`isUpcoming` 타입 오류 2건과 `vite.figma.config.ts`의 callable 오류 1건이 남는다. 기존 레거시와 미리보기 설정은 이번 보완에서 임의 변경하지 않았다.

## 미구현 — 출시 차단

- 실제 PG 승인/환불/웹훅·중복 결제 방지 원장, 카카오 승인/발송/재시도, 본인인증.
- 서버 로그인·당사자 권한·관리자 역할별 최소 권한, 계정 간 영구 동기화·DB 원자적 배정 잠금.
- 실제 파일 저장·형식/디코딩·GPS 제거·만료 사진 URL·서버 워터마크 합성·철회 후 접근 재검사.
- 정오/만남 당일 서버 시계·예약·최종 공개 작업, 감사로그 위변조 방지·보유/삭제 실행.
- 전체 타입검사 통과, 실기기·보조기술·전 상태 접근성 및 보안 검증.

## 출시 전 정책 확정 필요

환불, 교류비 미시작 처리, 교류 시작 후 중단/노쇼/약속 취소 대응, 재이용,
프로필·연락처 제공 범위/기간, 사진·편지·신고 증거·로그·백업 보유기간,
삭제/탈퇴 처리 절차와 법적 문서, 장기 대기 운영 기준/담당 대응 절차,
카카오 템플릿/반복 안내 허용 기준을 확정·고지해야 한다.
이 보고서는 임의의 새 환불·보유기간·노쇼 제재 정책을 확정하지 않는다.

실제 수집·과금·발송·자동 공개·배포는 수행하지 않았다.
