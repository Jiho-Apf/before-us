# V6-privacy-01-draft — 개인정보 보유·삭제·탈퇴

정책 UI와 가상 데이터 상태만 구현했다. 실제 법률 검토 완료가 아니며, 삭제·백업 파기는 예정 시각만 계산하고 실행하지 않는다.
기준값: `src/app/config.ts`의 `privacy` · 로직: `src/app/privacy-policy.ts` · 화면: `src/app/PrivacyPanels.tsx`

법적 보존자료는 일반 프로필과 분리하고 재매칭·광고 목적으로 사용하지 않는다.
탈퇴하면 편지·약속 상세도 원래 기한보다 빠른 7일 삭제 예정으로 당겨진다.

## 일시정지와 탈퇴

- 일시정지: 신규 소개만 중지. 소개 권리·결제·진행 중 교류 보존. 자료 삭제 없음.
- 탈퇴: 막지 않는다. 요청 전 종료되는 소개·교류·약속, 미공개 연락처 예약 취소, 환불·취소 요청 산정액을 보여 준다.
- 요청 즉시(가상): 상대 노출 중지, 신규 소개·접근 중지, 미공개 연락처 예약 취소, 서비스 처리 외 알림·마케팅 중지.
- 결제는 `requestPaymentCancellation`으로 환불·취소 ‘요청’ 상태만 만든다(환불 완료 아님). 진행 중 교류는 V6-conduct-01 본인 단순 변심 중단으로 기록돼 상대가 다음 소개비 면제를 받는다.
- 일반 자료 7일 이내 활성 삭제, 백업 30일 이내 순차 삭제 ‘예정’ 기록. 실행 상태는 `not-executed-demo`.

## 정정·삭제·처리정지

- 대상 자료를 골라 요청. 삭제·처리정지 대상이 법정 보존 기록과 겹치면 처리할 수 없는 항목·사유·기간을 요청 전에 안내.
- 운영자 결과: 처리 / 일부 처리 / 처리 불가. 법정 예외가 있으면 ‘처리’로 기록할 수 없음. 결과는 회원 화면과 기존 요청 진행에 함께 표시.
- 자료 삭제 요청은 탈퇴로 바뀌지 않는다.

## 신고 증거

- 사진·편지 전체 보관 금지. 분쟁에 필요한 항목(신고 설명·관련 약속 기록·관련 편지 일부·관련 사진 1장·연락처 악용 정황)만 1~3개.
- 사건 진행 중에는 기간을 산정하지 않고, 종결 시 +3년.

## 검증 범위

- 모델 시나리오 34건 통과(연락처 표시 창 경계, 편지 종료+30일, 약속+90일, 탈퇴 시 7일·30일, 교류비 미제공 DAY 16,000원 요청 생성, 법정 5년·3년 분리, 법정 예외 시 전부 처리 금지, 증거 3개 제한·종결 후 3년, 삭제 요청≠탈퇴, 진행 중 교류에서도 탈퇴 가능, 알림 중지).
- `/demo/privacy`에서 탈퇴 요청과 삭제 요청→운영 결과 기록→회원 표시를 실행 확인. `/profile`, `/profile?demo=agreement`, `/admin/settings` 렌더링, 콘솔 오류 없음, 360px 가로 넘침 없음.
- 실제 서버 삭제 작업·백업 파기·법적 보존 저장소 분리·법률 검토는 미구현이다.
