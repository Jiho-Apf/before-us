# V6-conduct-01 — 교류 중단·약속 취소·노쇼·재이용

기존 A/B·약속·연락처 공개 기능과 V6-refund-01의 DAY별 환불 산정은 그대로 유지한다.
기준값: `src/app/config.ts`의 `conduct` · 로직: `src/app/conduct-policy.ts` · 화면: `src/app/ConductPolicy.tsx`

## 교류 중단

| 사유 | 판정 | 중단한 사람 | 상대(피해자) |
| --- | --- | --- | --- |
| 본인 단순 변심 | 본인 기록 즉시 반영 | 미시작 DAY만 환불, 실제 시작 후면 초기 소개 혜택 종료 | 미제공 DAY 환불 + 다음 소개비 5,000원 면제(즉시) |
| 상대 미응답·중도 이탈 | 운영 확인 | — | 확인 후 미제공 DAY 환불 + 5,000원 면제 |
| 운영 문제 | 운영 확인 | 확인 후 미제공 DAY 환불 + 5,000원 면제 | — |
| 안전·신고 사유 | 운영 확인, 단순 변심 자동 판정 금지 | 확인 시 보호 대상 + 5,000원 면제 | 사유 비공개 |

## 약속 취소

- 시작 24시간 이전: 일반 취소 → 재조율 또는 종료 선택.
- 24시간 이내: 늦은 취소로 기록. 피해 상대가 교류를 종료하면 5,000원 면제.
- 응급·질병·사고·안전 사유: 운영자 확인 후 불이익 미적용(피해 상대의 면제는 유지).
- 시작 시각 이후에는 취소로 기록하지 않는다(노쇼 확인 대상).

## 노쇼

- 시작 30분 경과 + 사전 취소·연락 없음일 때만 신고 가능. 같은 약속에 상대의 취소 기록이 있으면 취소 기준으로 처리.
- 자동 판정 없음. 운영자 사실 확인 후 기본 14일 소개 이용 정지.
- 반복(이전 확인 노쇼 있음)·고의성: 30일 이상 또는 이용 종료를 운영자 검토 대상으로 표시만 함.
- 피해자: 5,000원 면제 + 우선 재소개. 정상 제공된 교류비 전체 자동 환불 없음.

## 재이용

- 첫 교류 실제 시작 전에는 기존 초기 혜택 유지(새 회차 아님).
- 정상 종료 뒤 새 회차 소개비 5,000원(면제 있으면 0원, 1회 적용), 새 상대 상호 선택 시 교류비 24,000원.
- 기존 프로필·사진·취향 재사용. 마지막 검토 후 90일 이상 또는 검토 기록 없음 → 사진·지역·직업·관계상태·선호 재확인.
- 이용 정지 중에는 새 회차 요청을 받지 않고 재검토 경로를 안내.

## 공개·기록

- 상대에게는 "약속이 취소되었어요", "교류가 종료되었어요" 수준만 표시. 사유·제재 내용은 본인에게만.
- 운영 결정마다 관리자 기록(시각·결정·메모)과 감사 로그(사건 ID·조치만, 원문 없음).
- 재검토: 판단 대상자는 불리한 기록에, 주장자는 주장이 인정되지 않았을 때 각 1회.

## 검증 범위

- 모델 시나리오 44건 통과(DAY별 24,000/16,000/8,000/0원, 24시간 경계, 30분 경계, 14일 종료 시점, 반복 검토 표시, 사유 비공개, 재이용 90일·면제 1회·중복 방지).
- `/demo/conduct`에서 단순 변심 중단·노쇼 신고→운영 확인→정지/면제 표시를 실행 확인, `/profile`·`/admin/safety` 렌더링·콘솔 오류 없음, 360px 가로 넘침 없음.
- 전체 타입 검사는 기존 3건(App.tsx 2건, vite.figma.config.ts 1건) 외 새 오류 없음.
- 실제 정지 집행·환불 지급·서버 원장·약관 법률 검토는 미구현이다.
