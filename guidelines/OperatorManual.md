## 1. 신청서 검토 기준

**통과 조건(모두 충족)**
1. 본인 인증 완료 · 만 19세 이상.
2. 필수 항목 작성 · 금지 표현 없음: 연락처, SNS 아이디, 외부 링크, 주민번호, 금전 요구.
3. 미혼·비연애 서약과 진술 체크. **서류로 확인하지 않는다.** "검증된 미혼" 같은 표현을 회원에게도 쓰지 않는다.
4. 관계 목적이 서비스와 맞음(진지한 연애 · 천천히 알아가며 연애 · 아직 정리 중).
5. 사진 기준 충족(§2).

**보완 요청**
- 이유는 템플릿에서 고른다: 얼굴 확인 어려움 · 동일 사진 · 흐림 · 타인 등장 · 현재 모습 재등록 필요.
- **해당 항목만** 다시 받는다. 다른 항목을 함께 지적하지 않는다.

**보류 또는 거절**
- 허위 정보 정황, 미성년 의심, 이전 이용 제한 계정과 같은 인증값, 다른 회원에게 해를 끼칠 위험이 보이면 거절한다.
- 거절 사유는 내부 기록에만 남긴다.
- 회원에게는 "이번에는 소개를 준비하기 어려워요"와 재신청 가능 여부만 안내한다.

**하지 말 것**
- 외모·학력·직업·소득으로 등급을 매기지 않는다.
- 사진으로 성격을 추측하지 않는다.
- 혼인 경력·종교·건강 정보를 묻지 않는다(민감정보, 결혼중개업 오해 위험).

| 1 대표 얼굴 | ✔ | 혼자, 정면 또는 가까운 구도, 얼굴이 또렷함. 마스크·선글라스·과한 보정 없음 | 얼굴 확인 어려움, 흐림 |

| 3 전체 스타일 | ✔ | 평소 옷차림, 전체 분위기. **노출·속옷·치수 인증은 요구하지 않는다** | 타인 등장 |

- 정지 화면 캡처나 외부 유출이 의심되면 즉시 공개를 중단하고 §4로 처리한다.

## 3. 소개 고르는 법 (한 쌍 준비)

1. **필수 조건 먼저 확인.** 양쪽의 꼭 필요한 조건(최대 3개), 나이 범위, 만남 가능 지역, 차단 목록, 이전 소개 상대가 겹치지 않아야 한다. 추천 보조 도구가 미충족 항목을 표시한다.
2. **추천 후보 3명 중에서 고른다.** 도구는 보조일 뿐이고, 최종 결정은 사람이 한다.
3. **공통점을 문장으로 적는다.** "운영진의 제안 이유"에는 두 사람이 직접 쓴 문장에서 찾은 공통점을 한 줄로 쓴다.
   - 좋은 예: "두 분 다 쉬는 날 동네 서점에 간다고 적으셨어요."
   - 나쁜 예: "잘 어울리실 것 같아요", 외모 언급.
4. **거절 이유 기록을 참고한다.** 지난 소개의 거절 이유(거리·나이·관심사 등)는 상대에게 보이지 않는 운영 참고 기록이다. 다음 후보를 고를 때 반영한다.
5. **성비 확인.** 한쪽 성별 신청이 70%를 넘으면, 많은 쪽 새 신청은 순서대로 대기한다. 대기 상태는 회원에게 투명하게 보인다.
6. **공개 전 재확인(11:40).** 준비 뒤 프로필·사진·선호가 바뀌었으면 다시 검토한다. 참여 확인이 안 된 회원은 공개하지 않는다.

**소개 간격:** 하루 최대 1명, 활성 소개는 1건이다. 서로 선택한 뒤에는 새 소개를 멈춘다.

## 4. 신고·안전 처리

| 등급 | 예 | 처리 |
|---|---|---|
| 긴급 | 위협, 성적 괴롭힘, 금전 요구, 미성년 의심, 연락처·사진 유포 | 운영시간 내 **4시간 안에** 확인. 즉시 교류·약속 중단과 연락처 공개 예약 취소. 증빙 보관. 필요하면 경찰 신고를 안내 |
| 일반 | 불쾌한 표현, 약속 반복 변경, 노쇼 | 1영업일 안에 확인. 양쪽 기록을 보고 판단 |
| 문의성 | 단순 불만, 오해 | 문의로 전환해 답변 |

- **노쇼**: 시작 30분이 지났고 사전 취소·연락이 없을 때만 인정한다. 확인되면 14일 소개 정지와 다음 소개 재확인 대상이 된다. 피해자는 다음 소개비를 면제한다.
- **늦은 취소**: 약속 24시간 이내 취소는 기록한다. 반복되면 이용 제한을 검토한다.
- 모든 제한에는 **재검토 요청 1회** 길을 열어 둔다. 판단 근거는 감사 기록에 남긴다.
- 상대에게는 취소·노쇼·제재 사유를 자세히 알리지 않는다.
- 회원 간 편지는 **신고가 들어온 경우에만**, 해당 교류에 한해 열람한다.

- 애매하면 회원에게 유리하게 처리하고, 판단 근거를 남긴다.

## 6. 고객 문의 응대

- **운영시간:** 평일 10:00~18:00(공휴일 제외). 문의 화면에도 같은 내용으로 안내한다.
- **첫 응답 목표**

  | 종류 | 목표 |
  |---|---|
  | 안전·신고 | 운영시간 내 4시간 |
  | 결제·환불 | 1영업일 |
  | 일반 | 1영업일 |
  | 제휴·기타 | 3영업일 |

- 운영시간 밖에 들어온 문의는 다음 영업일 오전에 **안전·신고 → 결제 → 일반** 순서로 처리한다.
- **답변 원칙**
  - 결론을 먼저 쓴다.
  - 회원이 할 일이 있으면 한 줄로 따로 적는다.
  - 상대 회원의 정보나 판단 이유는 알려 주지 않는다.
  - "죄송하지만 규정상" 같은 말로 끝내지 않고, 가능한 대안을 하나 제시한다.
- **기록:** 접수 번호로 상태(접수 → 확인 중 → 답변 완료)를 남긴다. 회원은 접수 번호와 이메일로 조회할 수 있다.
- **답변 템플릿(초안)**
  - 접수 확인: "문의 잘 받았어요. ○영업일 안에 답변드릴게요."
  - 환불 안내: "요청하신 환불은 ○○ 기준에 따라 ○○원이에요. 결제 수단으로 ○영업일 안에 돌아가요."
  - 안전: "알려 주셔서 고마워요. 지금 해당 교류를 멈췄고, 확인 결과는 ○일까지 알려드릴게요."
