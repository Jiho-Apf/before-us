# 출시 전 법률 검토 정리 (2026-10-15 · 일반 정보, 법률 자문 아님)

공개 자료(찾기쉬운 생활법령정보 easylaw.go.kr, 언론 보도 등)를 기준으로 조사했다.
law.go.kr 조문 원문은 직접 대조하지 못했으므로, **출시 전 변호사 검토와 원문 대조가 필요하다.**

## 1. 결혼중개업법 해당 여부 — 위험도: 중간 (상황에 따라 중간~높음)

**정의(제2조):** 결혼중개업은 "수수료·회비 등을 받고 결혼을 위한 상담·알선을 업으로 하는 것"이다. 대한민국 국적자끼리를 대상으로 하면 **국내결혼중개업**이며, 시·군·구 **신고** 대상이다.

**판단 요소와 플라비**

| 요소 | 플라비 |
|---|---|
| 결혼을 위한 것인가 | 목적 선택지에 결혼이 없고, 혼인경력·학력·소득을 받지 않음 → 위험을 낮춤 |
| 상담·알선 행위 | **운영자가 직접 1명을 골라 소개**하고 만남 일정도 조율 → 위험을 높임 |
| 대가 | 소개비·교류비를 받음 → 해당 |
| 업으로 | 반복적 영리 운영 → 해당 |

**최근 동향(2026)**
- 커플닷넷 사건: 지자체가 "매니저의 추천 개입"을 알선의 근거로 보고 영업정지를 통보했다. 법원이 집행을 정지했고 본안은 진행 중이다.
- 정부의 「2026 결혼중개업 실태조사」가 처음으로 미신고 데이팅·소개팅 앱을 조사 대상에 포함했다.
- 데이팅 앱이 결혼중개업에 해당하는지에 대한 공식 해석이나 판례는 아직 없다.

**당장 할 일(위험 완화)**
1. 광고·화면·약관에서 결혼 관련 표현을 쓰지 않는다(결혼, 성혼, 배우자, 결혼정보, 커플매니저). → 현재 공개 화면 점검 완료, 해당 표현 없음.
2. 혼인경력·학력·직업명·연봉·재산·종교·가족관계·결혼 희망 시기를 받지 않는다.
3. 운영자 역할은 "큐레이션·안전 검토"로 설명하고, 연애·결혼 상담은 하지 않는다.
4. 미혼 서약은 "현재 배우자·연인이 없음(안전·신뢰 목적)"으로 쓰고, 서류로 확인하지 않는다고 명시한다.
5. **관할 시·군·구 또는 주무부처에 국민신문고로 "결혼중개업 해당 여부" 질의**를 보내고, 회신을 보관한다. 구속력은 없지만 선의를 입증하는 자료가 된다.

**신고를 택할 경우의 요건**
- 건축물대장상 적격 사무실(2종 근린생활시설 또는 업무시설). 자택·온라인 전용으로는 어렵다.
- 보증보험 2천만 원 이상, 결격사유 확인, 신고 수수료 3만 원.
- 결혼중개 계약서(전자문서 가능)와 표준약관, 장부 5년 보관.
- 홈페이지 초기화면에 신고번호·수수료표·보증보험 청구절차 표시, 광고에 신고번호 표기.

**미신고로 결혼중개업을 하면:** 3년 이하 징역 또는 3천만 원 이하 벌금, 영업소 폐쇄 등.

## 2. 그 밖에 적용되는 법

| 법 | 해야 할 것 | 플라비 상태 |
|---|---|---|
| 전자상거래법 | 통신판매업 신고(면제 기준 확인), 사이트 초기화면 사업자 정보 표시(상호·대표자·주소·전화·이메일·사업자번호·통신판매업 번호·**호스팅 제공자**·사업자정보 확인 링크) | 푸터에 자리만 있음 → 사업자등록 후 채움 |
| 전자상거래법 청약철회 | 7일 원칙. 디지털·용역은 제공 시작 후 제한 가능하지만, **제한 사유를 결제 전에 분명히 표시해야** 인정됨. 가분적 용역은 남은 부분 환불 | 소개비(열람 전 전액)와 교류비(남은 날 환불) 설계는 적절함. 결제 직전 화면에 제한 사유 문구 보강 필요 |
| 개인정보보호법 | 처리방침 필수 항목(§3), 상대 회원에게 프로필·연락처를 주는 것은 **제3자 제공 → 별도 동의**, PG·본인인증·알림톡·호스팅은 **위탁**, 해외 서버면 국외이전 고지 | 제3자 제공 동의는 신청서에 있음. 처리방침 정식본 필요 |
| 민감정보 | 종교·건강·성생활 정보를 받으면 별도 동의 필요 | 받지 않음(유지할 것) |
| 정보통신망법·청소년보호 | 19세 미만 이용 불가 표시, 본인 확인, 광고성 알림은 사전 동의와 "(광고)" 표시, 야간 별도 동의 | 19세 이상 인증·푸터 표기 있음. 마케팅 동의 분리돼 있음 |
| 약관규제법 | 무효 위험 조항: 고의·중과실 면책, "어떤 경우에도 환불 불가", 일방적 해지·변경 간주, 부당한 관할 | 정식 약관 작성 시 피할 것 |
| 표시광고법 | "검증된 미혼", "무제한", "100% 매칭" 금지 | 미혼은 "본인 서약"으로만 표기 중 |

## 3. 정식 문서에 꼭 들어갈 것

**이용약관**
- 목적·정의, 이용 자격(19세 이상, 본인 인증, 미혼 서약은 검증하지 않음)
- 서비스 내용(정오 1명 공개, 상호 선택, 3일 교류, 4일째 선택, 연락처 당일 공개)
- 요금과 결제, 청약철회·환불(§5 표 그대로)
- 회원 의무와 금지 행위(허위 서약, 연락처 우회 교환, 외부 유도, 금전 요구, 괴롭힘, 녹음·유포)
- 이용 제한 절차와 재검토, 안전(신고·차단·증빙 보관)
- 책임 제한(고의·중과실 제외), 약관 변경(7일 전 공지, 불리하면 30일 전 개별 통지), 분쟁·관할, 사업자 정보

**개인정보처리방침**
- 처리 목적, 항목(필수/선택), 보유 기간(탈퇴 7일, 백업 30일, 편지 30일, 약속 정보 90일, 법정 보존 5년/3년/6개월)
- 파기 절차, 제3자 제공(상대 회원: 프로필·연락처), 처리 위탁(PG·본인인증·알림톡·호스팅)
- 국외이전(서버 위치에 따라), 민감정보 미수집 명시, 쿠키
- 정보주체 권리와 행사 방법, 안전성 확보조치, 개인정보 보호책임자 연락처, 권익침해 구제 방법, 변경 이력

## 4. 전문가 확인이 필요한 항목

1. 운영자 1:1 큐레이션 + 유료 만남 조율 구조가 결혼중개업에 해당하는지(커플닷넷 본안 판결과 2026 실태조사 결과 주시).
2. 국내결혼중개업의 교육 이수 의무, 보증보험 금액, 사무소 요건의 현행 원문.
3. 교류비(3일 용역) 환불 산식과 청약철회 제한 표시 문구의 유효성.
4. 통신판매업 신고 면제 기준과 면제 시 표시 방법.
5. Supabase·Vercel 리전과 법인 소재에 따른 국외이전 고지 범위.
6. 상대 회원에게 프로필·연락처를 제공하는 법적 근거 구조, "안전 증빙 3년" 보존 근거.
7. 약관의 면책·이용 제한·환불 조항.
8. 부가통신사업 신고 면제 여부, 주무부처 명칭 변경(여성가족부 → 성평등가족부) 반영.
